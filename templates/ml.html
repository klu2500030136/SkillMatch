Supervised Learning

Uses data where the outcome is already known. The model learns the relationship between employee features and a target (e.g., Attrition).

Unsupervised Learning

Looks for patterns, groups, or unusual records without using a known target label. Useful for discovering hidden structures in the data.

Algorithm Explanations

K-Means

DBSCAN

Isolation Forest

Looks for observations that are easier to separate from the rest of the data, which can indicate unusual patterns.
