SkillMatch

Employee Intelligence & Attrition Analysis

Project Overview

SkillMatch is an employee intelligence and machine learning application developed using the IBM HR Analytics Employee Attrition & Performance dataset. The system provides an end-to-end workflow for dataset exploration, missing-value analysis, preprocessing, feature identification using PCA, supervised and unsupervised machine learning, model evaluation, 5-fold cross-validation, and employee-level attrition prediction.

How SkillMatch Works

  1. Dataset: The employee dataset is uploaded and inspected.
  2. EDA: Data distributions and relationships are explored.
  3. Missing Values & Preprocessing: Data is cleaned and transformed for machine learning.
  4. PCA & Feature Identification: Features are examined and dimensionality reduction is analyzed.
  5. Machine Learning: Supervised and unsupervised techniques are applied.
  6. Model Evaluation: Models are evaluated using appropriate metrics.
  7. 5-Fold Cross Validation: Model performance is checked across multiple folds.
  8. Employee Prediction: A saved model is used to predict attrition for entered employee information.
